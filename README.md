# HR interface prototype

A static HTML/CSS prototype of employee cards, recruitment, member creation and sign-up screens. Earlier frontend design/development practice, not a complete HR management backend.

[Current software engineering portfolio](https://amenibensaadaportfolio.netlify.app/?utm_source=github&utm_medium=profile&utm_campaign=personal_brand).

## Explore locally

From the repository root:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000/`. Additional screens include `card_employees.html`, `recrutement.html`, `Addmember.html` and `signup.html`. Form layouts do not implement authentication or persistent employee management. Image/font/template assets retain their original attribution. No hosted demo or test coverage is claimed.
